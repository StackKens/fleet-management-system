# Fleet Management System

A web-based Fleet Management System developed as part of an internship project.

## Purpose

The system is intended to support the management and monitoring of organizational fleet activities.

The project is based on an initial assessment of the fleet management processes used within the organization.

## Problem Areas Identified

The initial assessment identified several areas involving manual processes and record management, including:

- Vehicle request and assignment
- Vehicle usage and trip records
- Fuel management
- Vehicle maintenance and repairs
- Requisition-related activities
- Fleet reporting

The organization also faces the challenge of having a limited number of available vehicles.

## Proposed System

The proposed system will provide a centralized platform for managing important fleet activities and information.

The main areas of the system will include:

- Vehicle management
- Driver management
- Vehicle requests
- Vehicle allocation
- Trip management
- Fuel management
- Maintenance and repairs
- Inspection and registration
- Reporting
- User and access management

## Development Approach

This project is being developed from the ground up with emphasis on understanding backend engineering concepts rather than relying heavily on boilerplates.

The development process will focus on understanding:

- How HTTP works
- How requests and responses work
- API design
- Routing
- Middleware
- Business logic
- Database design
- Data relationships
- Authentication and authorization
- Validation
- Error handling
- Testing
- Application architecture
