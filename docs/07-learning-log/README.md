# Process 07 — Learning Log

## Purpose

Use this file to record what you learned, what confused you, and what you were able to explain in your own words.

A learning log is useful because working code is not proof of understanding. The log helps us return to concepts and see progress over time.

## How to use it

After each learning session, add a short entry like this:

```markdown
## YYYY-MM-DD — Topic

### What I studied

Describe the concept in your own words.

### Files I read

- `path/to/file-one`
- `path/to/file-two`

### What I changed

Describe the small change, or write `No code change`.

### What I tested

Describe exactly what you clicked, typed, or ran.

### What I do not understand yet

Write the exact question you still have.

### One thing I can now explain

Complete this sentence:

> I understand that ...

### Evidence

Paste the relevant terminal output or describe what happened in the browser.
```

## Suggested first entry

```markdown
## First frontend session — Orientation

### What I studied

The difference between the browser, the terminal, and the React source code.

### Files I read

- `frontend/index.html`
- `frontend/src/main.tsx`
- `frontend/src/App.tsx`

### What I tested

I started the development server, opened the dashboard, clicked the navigation items, and used the browser Elements panel.

### What I do not understand yet

I still need to understand why `createRoot` connects React to the HTML page.

### One thing I can now explain

> I understand that the browser loads an HTML file and React renders the visible content inside the root element.
```

## Questions to bring to the next session

Bring specific questions, for example:

- What is a component?
- What is the difference between a prop and state?
- Why does the sidebar stay visible during navigation?
- What does `.map()` return?
- Why is the dashboard data temporary?
- What is the difference between frontend and backend?

Specific questions are easier to answer and debug than `I do not understand the project`.
